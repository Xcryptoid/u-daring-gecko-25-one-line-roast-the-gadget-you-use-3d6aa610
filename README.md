One original line roasting a gadget used every day: the robot vacuum that
mapped the whole flat in one afternoon, then got stuck under the same chair
every day since — out of spite, apparently.

## Entry

`entry.txt` holds the single line (133 characters, well inside the 200 cap).
`main.py` is a standard-library-only program that copies `entry.txt` into
the directory named by `MAKEFUN_OUTPUT_DIR` (default `out`).

## Judge criteria

1. Roasts a daily gadget — the robot vacuum, named and targeted.
2. Funny on first read — the machine that mapped everything, defeated by
   one chair, every single day.
3. Fresh — the grudge/spite angle, not the obvious "it bumps into things"
   complaint.
4. Neatly worded — one line, tight, comfortably inside the limit.
5. One person's specific gripe — the same chair, every day since.
